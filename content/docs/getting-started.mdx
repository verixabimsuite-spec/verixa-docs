# Getting Started

Verixa Suite is a professional productivity suite for Autodesk Revit. It helps BIM professionals manage Revit Families, automate repetitive tasks, improve documentation workflows, generate annotations, and increase project productivity.

## Key Features

- **Family Manager**: Organize, search, and load Revit families instantly.
- **Auto Annotation**: Automatically generate tags and dimensions.
- **Batch Sheet Maker**: Create hundreds of sheets from Excel schedules in seconds.
